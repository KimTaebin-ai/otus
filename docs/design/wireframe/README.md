# 42 Support 디자인 시스템 (wireframe 시절, 구버전)

> 2026-10-17부터 기준은 `docs/design/README.md`와 `final/`이다. 이 문서는 기록용으로만 남긴다.

이 폴더 이미지에서 추출한 규칙이다. 토큰 값은 `shared/styles/_tokens.scss`에 있다.

- **기준 순서**: Foundations.png → Cadet.png → 컴포넌트 이미지(Badge, Step, Uploaded row, Validation states) → 화면 와이어프레임(U01–U06).
- **화면 이미지는 회색조 와이어프레임이다.** 레이아웃과 문구는 와이어프레임에서, 색·radius·컴포넌트 모양은 Foundations와 컴포넌트 이미지에서 가져온다.
- **이미지 역할**: Cadet.png는 교육생 화면 공통 셸(사이드바 + 본문 배치)이고, 셸 디자인은 여기서만 가져온다. U01–U06 이미지는 셸 안 본문 영역만 그린 것이다. 사이드바가 안 보이는 건 생략일 뿐 "사이드바 없음"이 아니다(2026-10-16 결정).
- 이미지에 없는 디자인은 만들지 않는다. 필요하면 먼저 묻는다.

## 전체 컨셉

모든 화면 작업은 이 섹션을 따른다.

- **톤**: "하나의 흐름, 일관된 경험"(Foundations). 밝고 차분한 화면에, 강조는 청록색(teal) 하나만 쓴다. 문구는 "~해주세요", "~할 수 있어요"처럼 부드러운 존댓말이다.
- **색 쓰는 규칙**
  - 주색 `--color-teal`: 화면의 주 행동 버튼(제출하기), 활성 메뉴 글자, 텍스트 링크(변경, 도움말 보기), Step 숫자. 장식에는 쓰지 않는다.
  - `--color-mint`: 활성 메뉴 배경, 승인 배지, Step과 아바타 배경. teal의 옅은 짝이다.
  - 배경: 페이지와 카드는 흰색(`--color-surface`)이다. 보조 정보 박스(도움말 카드, 파일 아이콘 박스)는 `--color-bg`.
  - 상태색은 상태 표시에만 쓴다. **항상 텍스트와 함께 쓰고 색만으로 상태를 전달하지 않는다**(Foundations: "텍스트가 함께 있는 상태 표시").
    - teal/mint: 승인
    - blue: 검토 대기, 재검토 대기
    - red: 재검토 요청, 형식 오류
    - amber: 미제출, 전송 실패
    - gray(`--color-bg` + `--color-muted`): 임시 저장
  - 글자는 `--color-ink`(제목·본문)와 `--color-muted`(설명·메타·라벨) 두 단계뿐이다.
  - 그림자는 쓰지 않는다. 면은 `--color-border` 1px 테두리로 구분한다.
- **타이포 위계** (Noto Sans KR, 크기는 추정치)
  - 페이지 제목 28 bold
  - 카드 제목 20 bold
  - 알림 제목 16 bold
  - 라벨·버튼·메뉴 15 medium
  - 본문 14
  - 캡션·배지 12
- **레이아웃 원칙**
  - 왼쪽 고정 사이드바(228px)와 오른쪽 본문으로 나눈다. 사이드바는 /home, /submit, /history, /settings(U03–U06)에만 있다. /login(U01)과 /initial(U02)에는 없다. 본문은 페이지 제목 → 한 줄 설명 → 카드들이 세로로 쌓인다.
  - 카드는 흰 배경, 테두리, 큰 radius(16)다. 카드 안의 행과 알림 박스는 중간 radius(12), 버튼은 작은 radius(8)다.
  - 간격은 8px 체계다(카드 안쪽 여백 24, 행 안쪽 여백 16). 정보 밀도는 낮고 여백이 넉넉하다.
  - 한 화면의 주 버튼(teal)은 하나다. 보조 행동(임시 저장 등)은 흰 배경에 테두리가 있는 버튼으로 주 버튼 왼쪽에 둔다.

## 화면별 메모

- **U01 로그인**
  - 사이드바가 없다. 왼쪽은 소개 패널("42 지원금 서류 제출", "처음에는 4종, 이후에는 고용보험가입내역서를 제출해요."), 오른쪽은 로그인 카드("42 계정으로 로그인" primary 버튼 하나).
  - 쓰는 컴포넌트: 버튼.
- **U02 최초 4종**
  - 사이드바가 없다(셸 밖). 최초 4종 제출 전에만 오는 화면이라 가드 때문에 다른 메뉴로 갈 수 없다. 본문만 가운데 정렬한 온보딩 레이아웃이다.
  - 제목 → 설명 → 접수 기간 정보 박스 → 2열 구성(왼쪽: 서류 4종 행이 든 카드, 오른쪽: 안내 카드 "처음에만 4종 제출") → 하단 [임시 저장] [4종 서류 제출].
  - 각 행은 서류명, 설명, 오른쪽 "PDF 선택"이다.
  - 쓰는 컴포넌트: 업로드된 파일 행, 알림·검증 박스, 버튼.
- **U03 홈**
  - 인사("동민님, 반가워요") → 이번 달 할 일 카드(발급 기준·마감 + primary CTA) → 2열 카드(최근 제출 이력 / 내 정보: 취업 상태·마스킹 계좌) → 접수 시작 안내 정보 박스 → 제출 대상 확인 카드.
  - 쓰는 컴포넌트: 사이드바, 버튼, 상태 배지.
- **U04 월별 제출**
  - 제목 → 발급 기준·접수 기간 정보 박스 → 카드(기존 3종 "유지" 비활성 행 + 고용보험 PDF 업로드 영역("파일 선택 또는 끌어놓기", [PDF 선택]) + 각주) → [임시 저장] [제출하기].
  - 쓰는 컴포넌트: 업로드된 파일 행(비활성), 알림·검증 박스, 버튼.
- **U05 이력·보완**
  - 제출 이력 표(제출 월 / 제출일 / 처리 상태) → "보완 요청이 있는 경우" 카드(사유 박스 + 새 파일 행 + primary "9월 30일 23:59까지 보완 제출").
  - 쓰는 컴포넌트: 상태 배지, 업로드된 파일 행, 버튼.
- **U06 사용자 설정**
  - 지급 계좌·통장사본 카드(은행·계좌번호 입력 + 통장사본 파일 행 "변경" + [계좌 변경 저장]) → 취업 상태 라디오 카드(선택 즉시 저장 안내) → 개명·계좌 변경 안내 카드([개명 정보 제출] [변경 요청 이력]).
  - 해커톤 범위는 취업 상태뿐이다(CLAUDE.md). 계좌·개명은 범위 밖이다.
  - 쓰는 컴포넌트: 업로드된 파일 행, 버튼.

## 이미지끼리 다른 부분

1. **주 버튼 색**: 와이어프레임은 진회색이고, Foundations는 teal이다. → teal을 쓴다.
2. **모서리**: 와이어프레임은 직각이다. Foundations와 컴포넌트 이미지는 둥근 모서리(8/12/16, 배지는 pill)다. → 둥근 모서리를 쓴다.
3. **사이드바 배경**: 와이어프레임은 회색 면이고, Cadet은 흰 배경에 오른쪽 테두리다. 로고도 와이어프레임은 "42 SUPPORT" 한 줄이고, Cadet은 큰 "42" + SUPPORT + 태그라인이다.
4. **메뉴 이름**: 와이어프레임은 홈 / 서류 제출 / 제출 이력 / 사용자 설정이다. Cadet은 홈 / 서류 제출 / 내가 낸 서류 / 내 정보이고 아이콘이 있다. U05 제목은 "내가 제출한 서류", U06 제목은 "동민님의 정보"다. → **Cadet 메뉴명을 쓴다**(2026-10-16 결정).
5. **사이드바 하단**: 와이어프레임은 이름과 login 텍스트만 있다. Cadet은 도움말 카드와 아바타가 있고 "· 카뎃"이 붙는다. 도움말 링크의 목적지는 범위 밖이다.
6. **상태 라벨**: Foundations와 U05는 "검토 중"과 "보완 요청"을 쓰고, api.md는 "검토 대기"와 "재검토 요청"을 쓴다. → api.md 라벨을 쓴다.
7. **파일 행**: 와이어프레임은 회색 "PDF" 박스와 오른쪽 muted "PDF 선택"이다. Uploaded row는 teal 문서 아이콘과 teal "변경"이다. 업로드 전과 후의 상태 차이로 보이지만, 업로드 전 행의 색 디자인은 없다. 【확인 필요】
8. **U01 버튼**: 와이어프레임은 "42 계정으로 로그인"이고, 현재 구현은 데모 로그인(ID 입력)이다. 42 OAuth는 아직 백엔드에 없다.
9. **U02 사이드바**: U02만 사이드바가 없다. 현재 `app.routes.ts`는 `/initial`도 shell 안에 있다. → **해결(2026-10-16 결정)**: U01–U06 이미지는 본문만 그린 것이고 셸은 Cadet.png에서 가져온다. 사이드바는 /home, /submit, /history, /settings에만 둔다. /login과 /initial은 셸 밖이고, /initial은 본문만 가운데 정렬한 온보딩 레이아웃이다.
